# 🍽️ Catering Management System

A web-based application designed to manage catering services and streamline booking operations.

## 🚀 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Environment:** XAMPP

## ✨ Key Features

- Catering service management
- Booking management
- Database integration
- Dynamic web interface

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/SIVATS-lab/catering-management-system.git
   ```
2. Move the project folder into XAMPP's `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Create the required MySQL database and import the project's SQL file, if included.
5. Configure the database connection in the PHP configuration file.
6. Open `http://localhost/catering-management-system/` in your browser.
